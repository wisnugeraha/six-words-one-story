Write a complete story in exactly six words, on any subject. The entry is a
program that writes that six-word story to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` (the six-word story) to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
